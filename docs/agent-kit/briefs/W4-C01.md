# Stream W4-C01: MIR lowering: index, or‑patterns, ranges, slices, guards, struct/spread

## Mission
Implement Complete MIR lowering for all HIR nodes: `Expr::Index` → `Place` with `ProjectionElem::Index`. `Pat::Or` → `SwitchInt` over discriminant values. `Pat::Range` → `SwitchInt` for small ranges, comparison chain for large. `Pat::Slice` → length checks and indexed binds. Match guards → conditional branch after pattern test. `Expr::Struct` → `Rvalue::Aggregate` with spread via field copies. Ensure all bindings produce correct locals. for the Glyim compiler.

## Test Location (MANDATORY)

**ALL tests MUST be written as unit tests in `src/tests/` within the crate.**

NEVER use the `tests/` directory at the crate root (integration tests). Unit tests compile faster because they share the crate's private API.

### Setup Pattern

1. In `crates/glyim-lower/src/lib.rs`, add:
   ```rust
   #[cfg(test)]
   mod tests;
   ```

2. Create `crates/glyim-lower/src/tests/mod.rs` declaring submodules:
   ```rust
   mod module_a;
   mod module_b;
   ```

3. Each test file contains `#[test]` functions with full access to `pub(crate)` items.

4. Add `glyim-test` as a dev-dependency:
   ```toml
   [dev-dependencies]
   glyim-test = { workspace = true }
   ```

5. Read `docs/agent-kit/GLYIM_TEST_INSTRUCTIONS.md` for full API reference.
