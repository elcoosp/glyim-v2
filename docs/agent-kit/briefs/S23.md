# Stream S23: Build Tool – Dependency Resolution and Caching

## Mission
Implement In `crates/glyip/src/dep.rs`, implement `DependencyResolver::resolve` to parse `Glyip.toml`, fetch dependencies from `CrateIndex` or local path, and produce `Lockfile`. Implement `CrateIndex` loading from a local registry cache (or HTTP index). In `cache.rs`, implement `Cache::store_artifact` and `get_artifact` to store compiled object files in `target/debug/deps`. In `fingerprint.rs`, implement `FingerprintStore::load_from_dir` and `save_to_dir` using SHA‑256 of file contents. In `commands.rs`, implement `cmd_build` to use incremental fingerprinting and only recompile changed crates. Add support for `--release` and `--target`. Implement `cmd_test` to run `cargo test`‑like test discovery and execution (using `glyim_test` harness). for the Glyim compiler.

## Test Location (MANDATORY)

**ALL tests MUST be written as unit tests in `src/tests/` within the crate.**

NEVER use the `tests/` directory at the crate root (integration tests). Unit tests compile faster because they share the crate's private API.

### Setup Pattern

1. In `crates/glyip/src/lib.rs`, add:
   ```rust
   #[cfg(test)]
   mod tests;
   ```

2. Create `crates/glyip/src/tests/mod.rs` declaring submodules:
   ```rust
   mod module_a;
   mod module_b;
   ```

3. Each test file contains `#[test]` functions with full access to `pub(crate)` items.

4. Add `glyim-test` as a dev-dependency:
   ```toml
   [dev-dependencies]
   glyim-test = { workspace = true }
   ```

5. Read `docs/agent-kit/GLYIM_TEST_INSTRUCTIONS.md` for full API reference.
